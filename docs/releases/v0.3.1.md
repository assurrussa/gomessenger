# GoMessenger v0.3.1

This patch release corrects runtime supervision and health-probe races. The root tag is published;
nested module publication and the complete clean published-consumer gate are still pending.

## Changes

- A managed service that calls `runtime.Goexit` is reported as an unexpected non-returning exit. The runtime cancels
  its peers and follows the normal shutdown path; it does not classify the exit as a recovered panic.
- `Readiness` and `DeepHealth` recheck runtime state after service callbacks and fail if drain or closure was observed.
  `Liveness` remains valid during drain, but fails after closure. Callback errors remain classifiable with
  `errors.Is` and `errors.As`. The final state check is a snapshot, not a guarantee against subsequent transitions.

## Upgrade from v0.3.0

Go remains on 1.27 and GoBus remains pinned to v1.2.1. The immutable root v0.3.1 module has no Outbox dependency.
The nested release layers adopt published Outbox root and corresponding database backends at v0.16.0, including
worker-exit supervision and Goexit-safe transaction rollback. No new migration or GoMessenger public API is required.
Keep Outbox root and any directly used backend on v0.16.0 together.

After every dependency-ordered tag resolves and the published-consumer gate passes, keep all used GoMessenger modules
on v0.3.1. Until then, the README continues to advertise the published v0.3.0 module set.

## Release evidence

The runtime fixes were reviewed in [PR #31](https://github.com/assurrussa/gomessenger/pull/31).
Source checks on merge commit `d33b075ffcedce654572038501708b375b57f53c` passed in
[CI](https://github.com/assurrussa/gomessenger/actions/runs/37098718485), including PostgreSQL and both Kafka matrix jobs.
These results are source evidence, not published v0.3.1 verification. Each subsequent release-layer commit still needs
its applicable source and current-head review gates.

Root v0.3.1 is published at `8d2501cc0aea4ebc4de5b93b13bd49a6dfd1fe17`. Its isolated anonymous consumer compiled and
passed checksum verification through the public Go proxy with no replacement or VCS fallback. This root-only result
does not establish published resolution of the nested modules.

Root, module, transport and final CLI layers must be prepared, reviewed and published in dependency order as described
in the [release process](../release.md). Final publication requires
`make test-consumer-release VERSION=v0.3.1` without development replacements.

The real-service pilot remains pending. This patch does not establish production readiness or exactly-once effects.
